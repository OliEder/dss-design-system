# Plan: Karten (Paket 4)

Spec: `docs/superpowers/specs/2026-10-10-live-karten-namen-design.md`. Branch `feat/karten`. Drei Teile, je eigene Commits und Tests.

## Teil A: PlayerCard mit Bild
- Props `photo?: string`, `photoAlt?: string` (Standard leer, dekorativ). Svelte `svelte/PlayerCard.svelte`, React `react/PlayerCard.tsx`, CSS `dss-pc-av*`, `dss-pc-hero--photo`.
- Anordnung: compact und standard zeigen das Foto als Avatar (32 px rund, 64 px abgerundet) an der Stelle der Trikotmarke; die Trikotnummer bleibt als Badge (`dss-tn--badge`) an der unteren rechten Ecke. Zeilenhöhe der compact-Zeile bleibt (Text bestimmt die Höhe, nicht der Avatar). hero: Porträtfläche links bis zum Kartenrand mit Verlauf nach Dunkel; unter 560 px Banner oben, der Name liegt über dem dunklen Verlauf.
- Fallback: `photo=""` oder Ladefehler (`onerror`) zeigt die bisherige Trikotmarke; ohne `photo` bleibt das Markup unverändert.
- Demo-Fotos: `stories/assets/players/*.jpg` aus dem lokalen `images/` (Unsplash), mit `CREDITS.md`.
- Doku: `CardLibrary.mdx` Abschnitt Spielerkarte (Beispiele, Controls `photo`/`photoAlt`, Code, Dos/Don'ts, Datenschutzhinweis).
